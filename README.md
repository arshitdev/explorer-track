# _Chess OOP Engine_

This is part of my coding cafe course @ Plaksha. I am building a chess engine with clean OOP design which is modular and supports modifing capabilites of pieces, adding new pieces and also exploring different chess bot strategies. Refer to [proposal](PROPOSAL.md) to know more about it.

# Instructions
1. Use my OOP library by importing chess module (no dependency required)
2. If you want to play a chess game, there is a pygame gui which you can launch:
   - Install dependencies using `pip install -r requirements.txt`
   - Launch it using `python chess/gui/pygame.py`
